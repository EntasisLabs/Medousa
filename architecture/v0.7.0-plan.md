# Medousa 0.7.0 — Accounts, Liquid depth, Browser + Languages

Living implementation notes for the three-pillar 0.7.0 release. Source plan: `.cursor/plans/0.7.0_three_pillars_b6c8c88e.plan.md`.

Locked choices: **OAuth = coding-agent login + ChatGPT as a chat path (1C)** · **Browser = click/type act + polish (2B)**.

## Pillars

1. **Account connections (ChatGPT + Cursor)** — sign into vendor accounts to unlock coding agents; ChatGPT subscription doubles as a chat path via Codex ACP.
2. **Richer Liquid + notes** — shared CSV/Excel paste, per-chart export, note HTML/Markdown export, grammar check.
3. **Browser act + script languages** — `cognition_browser_act` on the shared Web tab; HTML/CSS/JS/XML/JSON syntax highlighting in the Scripts editor.

## P1 — Account connections

Medousa does **not** scrape chatgpt.com or invent unofficial OAuth clients. Sign-in **orchestrates official vendor CLIs** already used by ACP; credentials stay in the vendor's own store.

| Slice | Status | Notes |
|-------|--------|-------|
| ACP auth status probe | ✅ | `medousa-acp-client` `RuntimeAuthProbe`; daemon `agents.rs` surfaces `auth_status` / `binary_present` / `auth_detail` in `AgentRuntimeInfo`; `create_agent_session` returns 401 when signed out |
| Connections UI | ✅ | Settings → **Connections** (`SettingsConnectionsSection.svelte`) — ChatGPT + Cursor cards, sign in/out, status refresh |
| Vendor CLI login orchestration | ✅ | `account_connections.rs` — ChatGPT via `codex login --device-auth` (system browser), Cursor via terminal `agent login`; sign-out via `codex logout` / `agent logout` |
| Runtime picker gating | ✅ | `ChatRuntimePicker.svelte` disables signed-out runtimes with sign-in CTA; Codex relabeled **ChatGPT / Codex** |

ChatGPT as chat LLM path = first-class Home runtime on **Codex ACP** (subscription), not a fake OpenAI API key. Native Medousa tool-loop + provider `openai` remain **BYOK**. Medousa Cloud magic-link stays deferred.

## P3 — Browser act + script languages

| Slice | Status | Notes |
|-------|--------|-------|
| `cognition_browser_act` | ✅ | `src/browser_act_tools.rs` — click/type/press/scroll/select/wait, gated on `supports_browser_host`; high-risk targets need `allow_high_risk` |
| Desktop exec | ✅ | BrowserHost `POST /v1/tab-groups/{id}/act` → `human_browser::browser_act_embed` (eval JS in the embed webview); blocked unless `control === agent`; `awaiting_operator` blocks act |
| iOS exec | ✅ | Client-executed session (mirrors search): daemon session + SSE → `human_browser_ios::human_browser_act` → `POST /v1/browser/sessions/{id}/complete-act`; chat store auto-executes `client_act` sessions |

| Script editor languages | ✅ | `codeEditorLanguageRegistry.ts` — `javascript`/`json` promoted stub→highlight; `html`/`css`/`xml` added; `@codemirror/lang-*` deps wired |

BrowserHost `:7422` fallback only when no matching human tab. Playwright/CDP sidecar, Google-first SERP, form-recording macros stay deferred.
