# Medousa 0.7.1

**A Windows stability patch for the 0.7 coding room.**

This is a **full-train patch release**. Engine, adapters, MCP gateway, coding
engine, shell session, local brain, desktop, and installer artifacts all carry
the **0.7.1** channel stamp.

## Fixed

- Projects can be discovered and opened from mounted Windows drives, including
  repositories under `C:\\...` outside the user profile. Paths are still
  canonicalized and constrained to connected-workshop drive roots.
- Captured Git, project-check, and repository-provider commands use hidden
  Windows subprocesses, preventing console windows from flashing during normal
  coding-room activity.
- Interactive terminal sessions keep their PTY behavior; the subprocess change
  applies only to daemon-owned commands whose output is captured.
- Vault Versions applies the same rules to history, restore, diff, selective
  saves, advanced worktrees, and portable-Git extraction. Home coalesces
  simultaneous status requests so view transitions perform one Git probe.

## Upgrade notes

- Restart Medousa after updating so the desktop replaces the bundled daemon and
  workshop sidecars with the 0.7.1 packages.
- Existing projects, undertakings, workspace tabs, and terminal sessions are
  preserved.
