# Medousa 0.11.0

**Make, mark up, and act through visual chat—while browser and desktop work stay
under workshop custody.**

This is a **full-train release**. Engine, adapters, MCP gateway, coding engine,
shell session, computer driver, local brain, desktop, and installer artifacts all
carry the **0.11.0** channel stamp. Companion integrations remain independently
versioned.

## Expressive chat

- Draw in the composer with the same pressure brushes, eraser, selection, move,
  undo, and zoom behavior as drawing notes. Editable vector ink and a PNG preview
  travel together through the transcript.
- Ask Medousa to generate an image. Progress shows in the turn, bytes stay on the
  workshop daemon, and you can refine, save to vault, copy, share, or download.
- OpenAI API-key Image generation is the supported programmatic lane. ChatGPT
  sign-in continues to power conversation models separately.

## Interactive recipes

- Answers that benefit from steps can arrive as interactive recipes or procedures
  with ingredients, ordered instructions, and step timers.
- Timers use absolute deadlines, survive app suspension, and can schedule a local
  notification after permission is granted. Timer controls do not create model
  turns; explicit follow-up buttons do.

## Governed worlds on browser and desktop

- Browser and computer actions run inside runtime-owned worlds pinned to an
  owning workshop, with causal activity, recovery checkpoints, and destination
  presentation streaming.
- The macOS computer-driver package observes the desktop and performs guarded
  native actions for turns that opt into computer use.
- Home can review governed world activity and surface driver readiness without
  moving custody out of Medousa.

## Teammates, teaching, and remote work

- **Bots** keep a name, purpose, archetype, memory, and primary conversation
  distinct from turn modes (General, Teacher, Instant, Coder).
- Teacher mode and narration help guided explanations stay readable.
- Coder work can attach the current checkout, produce portable Forge checkpoints,
  run on an authorized remote workshop, and reconcile signed results under peer
  execution policy.

## Upgrade notes

- Restart Medousa after updating so the app, bundled daemon, and optional package
  sidecars all run the 0.11.0 train. Update mobile builds for drawing, recipes,
  and embedded-daemon parity.
- Existing vaults, sessions, conversations, bots, projects, Forge work, account
  connections, and local-model configuration are preserved.
- Image generation requires an OpenAI API key and an Image generation model
  assignment under Settings → Models. ChatGPT sign-in alone does not bill or
  authorize the Platform Image API lane.
- Install or update the **computer-driver** package on macOS before using
  governed desktop observation or actions.
- Companion integrations remain on their independent release line.
