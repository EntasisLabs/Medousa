# Medousa 0.8.0

**Draw what words and structured blocks cannot—and enter the same Medousa workshop from the editor or browser already in front of you.**

This is a **full-train release**. Engine, adapters, MCP gateway, coding engine, shell session, local brain, desktop, and installer artifacts carry the **0.8.0** channel stamp. Companion integrations remain independently versioned at **0.1.0**.

## Draw in the vault

- Type `/draw` in a Live note to add an editable drawing block.
- Create a **Drawing** note to open the same native Svelte/SVG surface as a full note view.
- Pen, eraser, color, width, undo, redo, touch, and pointer input work without a React bridge.
- Drawings remain ordinary daemon-owned Markdown. A versioned base64url vector scene keeps Markdown scanners safe while leaving room for future shapes, text, pressure, and migrations.
- Preview and rendered exports freeze the visible canvas; Markdown export preserves the editable scene.

## Medousa anywhere

The first companion release includes:

- **VS Code 0.1.0** — bundled chat sidebar, conversation library, editor context, streaming, and reviewed code application.
- **Neovim 0.1.0** — a native coding room, visual/range context, conversation switching, diagnostics, permission prompts, and unified-diff application.
- **Browser 0.1.0** — a Chromium side panel with page-aware context and explicit host permissions.
- **Obsidian 0.1.0** — vault-native chat, bounded note context, Medousa vault search, backlinks, and create-only note workflows.

These bundles are tested and attached to GitHub Releases and uploaded to the Medousa release CDN by the same CI/CD train as the app.

## Local inference and concurrency

- Local inference now uses benchmark-informed device admission, dynamic CPU/GPU budgets, leases, generation fencing, and pressure-aware worker eviction.
- Workshop execution supports true concurrent multi-agent work while retaining durable session ownership and recovery.

## Upgrade notes

- Restart Medousa after updating so the desktop replaces its bundled daemon and package sidecars.
- Existing vault notes, drawings, sessions, work histories, and local model configuration remain in place.
- Install companion bundles separately; their 0.1.0 version is intentionally independent of the Medousa 0.8.0 train.
