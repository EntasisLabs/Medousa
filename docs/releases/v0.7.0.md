## Highlights

### A real coding room

Projects load before optional indexing begins. The coding room combines a fast
tree and editor with checks, tests, source navigation, Detamu understanding,
review, recovery, and replaceable Cursor or Codex executors.

### Terminal as a first-class workspace

Workshop-owned PTY sessions support real VT behavior, resizing, multiline
input, full-screen TUIs, splits, and restored terminal tabs. Terminal work can
remain attached to the same undertaking and evidence trail.

### Forge owns the work

Agents are executors, not authorities. Forge owns the undertaking, governed
worktree, lease, evidence, review decision, and final disposition. A user can
replace an executor without losing custody or history.

### Your room comes back

Desktops, panes, tabs, active documents, code drafts, and terminal sessions are
checkpointed and restored. Each workshop has an isolated snapshot, so remote
work IDs, note paths, streams, and editor buffers cannot leak into Personal or
another workshop.

### Calm under load

Language intelligence is incremental and Rust Analyzer is opt-in for large
projects. File-open and readiness events are deduplicated, expected indexing
states no longer become retry storms, and idle UI work no longer drives memory
growth or freezes interaction.

## Upgrade notes

- Restart Medousa after updating so Home replaces older daemon, coding-engine,
  and shell-session processes with API-compatible 0.7.0 packages.
- Existing work is preserved. The first launch migrates the old unscoped Home
  workspace snapshot into the Personal workshop only.
- Code intelligence remains optional and starts after the project is usable.
- macOS desktop and installer bundles require Developer ID signing and
  notarization; the release workflow fails instead of publishing unsigned Mac
  artifacts when those credentials are absent.
