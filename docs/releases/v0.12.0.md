# Medousa 0.12.0

**Design, build, and refine inside the same workspace.**

Medousa 0.12.0 adds Create, connects visual designs to repository work, and brings
Chat, Create, and Code to independent desktop windows through Desktop Spotlight.
It also expands Reviews and improves the everyday behavior of Code, browser
previews, terminals, and workshop switching.

This is a **full-train release**. Engine, adapters, GitHub reviews, MCP gateway,
coding engine, shell session, computer driver, local brain, desktop, and installer
packages carry the **0.12.0** stamp. Companion integrations retain their independent
versions.

## Create

- Sketch, compose images, diagram, and wireframe on a canvas with editable frames,
  layers, and groups. Drawing reuses the brushes, erasers, and movement behavior
  from Notes.
- Work with rich typography, real arrowheads and endpoint controls, object
  rotation, rounded shapes, shadows, grids, alignment, and snapping.
- Floating Style and Details controls keep the canvas available. Tool settings
  are remembered, and autosave preserves the current interaction.
- Give AI the visible design and image references, then keep refining in a
  continuing conversation. Generation jobs belong to the workshop runtime;
  preview, apply, and undo remain explicit.
- Continue editing during generation. Results remain available, and application
  checks the current document rather than discarding an image after any edit.

## From a design to a working UI—and back

- Select a frame and ask Medousa to implement the design in a repository using
  the existing coding runtime.
- Import a running site into Create as editable objects. Full-page capture can
  create stacked viewport frames, with the original capture available on demand.
- Adjust the design, then use **Update Code** to request source changes. Canvas
  dragging does not silently rewrite the repository.

## Desktop Spotlight and independent windows

- Press **⌘ Shift Space** on macOS or **Ctrl Shift Space** on Windows/Linux to
  open Desktop Spotlight over the current app. The tray/menu-bar entry is also
  available.
- Search conversations, Create projects, and Code projects. Open work in native
  windows, or focus the existing window for the same resource.
- Each work window retains its workshop. Switching the main shell detaches its
  subscriptions while accepted turns, jobs, and development servers continue.
- Saved canvas changes and chat receipts synchronize between views. Existing
  revision checks protect dirty drafts; closing a work window saves pending
  changes and keeps it open if saving fails.

## Reviews, Code, and browser previews

- GitHub pull requests and Forge reviews share a focused review experience, with
  typed change totals, labels, quick reviewer selection, checks, and merge status.
  GitHub-specific behavior belongs to the optional **GitHub reviews** package.
- Code gains a unified toolbar, compact actions for long breadcrumbs, a quieter
  Run picker, and tab dragging for split views.
- Development output supports terminal formatting and clickable links. Server
  Stop controls settle when the process exits, and browser sessions recover
  after an app or daemon restart.
- Main-shell requests continue to work with embedded browser views, including
  browser children that remain hidden after navigation.

## Chat and shared work

- Durable messages can move between native conversations and Bots on paired
  workshops. Handoff context is bounded, with explicit authority for follow-up
  work and process-completion wakes.
- Assistant commands use owned native terminals. Spotlight can open workshop
  terminals and saved SSH targets, and Activity keeps running work discoverable.
- ChatGPT account sign-in and model selection are updated. Streaming Markdown,
  artifact cards, reading position, and transcript memory receive reliability
  fixes.

## Upgrade notes

- Update Medousa and restart it so the app uses its newly bundled daemon. Update
  optional packages through **Settings → Packages**; remote package installation
  follows the remote workshop's filesystem authority.
- Update **GitHub reviews** to use the current provider controls. Install it in
  Settings for a local workshop, or run `medousa pull review-github` on the remote
  workshop host.
- Desktop Spotlight requires Medousa to remain running. If the shortcut is owned
  by another app, use the tray/menu-bar entry; Medousa reports the registration
  issue in Spotlight.
- Desktop windows and the global shortcut are desktop features. Mobile retains
  its existing navigation while receiving the Create and shared-runtime changes.
