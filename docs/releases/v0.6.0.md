## Highlights

### Shared mode & peer mesh
Profiles act as seats without a login. Pairing carries `profile_id`. Peer mesh adds capability-scoped messaging, inbox/outbox, receipts, grants, intros, and introducer wiring so personal and team workshops can talk on purpose (ADR-011).

### Mobile Home
Greeting leads; workshop + status + peers sit on one quiet meta row. Destinations menu puts custom views before More and pins Settings at the end. Settings rotates through every section with arrows. Host copy is platform-aware (no hardcoded “This Mac”).

### Calendar, shell & Spotlight
Reminders and richer calendar actions. Shell tabs gain notch orientation, drag-to-split, rename/search. Spotlight relevance pass. In-app desktop update check/download from Settings → Workshop → App.

### Dynamic & docs
ACP/MCP handlers and stream events filled in. Operator’s Guide expanded with product voice and Liquid examples. Context map and custom canvas editing improved.

---

## Upgrade notes

- **Engine + app:** ship together when using Shared mode, peer mesh, or calendar reminders — older engines won’t expose the new surfaces.
- **Pairing:** re-pair phone / portals after major host rebuilds if Shared seats mis-route.
- **Mobile:** More hub list is gone — More opens destinations; back from nested More returns Home.
- **Settings:** section ids are unchanged; mobile pager visits all sections (Preferences → … → Workshop).
- This cut ships **engine + desktop** only (`ship_engine` + `ship_desktop`). Adapters, installer, mcp-gateway, and local-brain stay on **0.4.1** channel artifacts. Do **not** push a `v0.6.0` full-train tag unless every package stamp is raised together.
