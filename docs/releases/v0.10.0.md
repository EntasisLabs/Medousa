# Medousa 0.10.0

**Your whole workspace now lives on every device—and stays responsive as the
conversation and the work get bigger.**

This is a **full-train release**. Engine, adapters, MCP gateway, coding engine,
shell session, local brain, desktop, and installer artifacts all carry the
**0.10.0** channel stamp. The VS Code, Neovim, browser, and Obsidian companions
remain independently versioned at **0.2.0**.

## A Personal workshop on every device

- iPhone and Android builds can run the Medousa daemon on-device. Mobile is no
  longer limited to being a portal into a computer.
- Chat, Notes, Calendar, Automations, agents, flows, history, model routing, and
  workshop state use the embedded Personal workshop, with pairing left as an
  optional way to reach another machine.
- Mobile onboarding now offers the same two useful model paths as Settings:
  connect a ChatGPT account or search providers and models and enter an API key.
- Home was rebuilt as a calm return point for today's note, current work,
  projects, and relevant activity. Quiet peer status stays quiet.
- Calendar, Automations, Workshop, Code, Notes, chat history, menus, action
  popovers, and expandable sheets now share consistent type, spacing, touch
  targets, and navigation.

## Long conversations that stay light

- Transcript history is fetched in pages as you move upward instead of loading
  the entire conversation into the app at once.
- Older pages preserve the visible scroll anchor, and the sticky user turn now
  follows the response currently in context instead of always pinning the final
  user message.
- A chronological turn stream keeps prose, reasoning, tool activity, and
  completion in their true order through reconnects and embedded execution.
- Prompt stashes preserve unfinished text and attachments. Committed history
  forks let a conversation branch from an earlier turn, and indexed transcript
  search makes old work findable without scanning every file.

## More ways to work, under Medousa custody

- Hermes joins Medousa, Codex, and Cursor as a first-class external ACP runtime.
  Medousa checks readiness, guides setup, exposes the runtime in chat, and keeps
  Coder work inside the governed project worktree.
- MCP connections now support the complete OAuth lifecycle: browser
  authorization, credential resolution, refresh, revocation, and reconnect.
- Daemon-owned OCI work environments can checkpoint, resume, delegate to another
  workshop, select a target, reconcile parallel results, and retain durable job
  custody across disconnects.
- The human Code workbench opens projects with one tap, reconnects task output,
  attaches tasks to terminal sessions, understands repository roots, and unifies
  editor, feedback, and review actions.

## A foundation built for bigger work

- Turn execution now has exact workshop and generation ownership, bounded
  admission, cancellation deadlines, and durable continuation rules.
- Provider streaming applies backpressure instead of growing an unbounded delta
  queue. Feed, workspace, transcript, Forge, Coder, and vault persistence use
  bounded logs, atomic mutations, generation fences, and explicit replay gaps.
- A generated API contract keeps route policy, OpenAPI, SDKs, Tauri bridges,
  wire types, and error envelopes in sync.
- Desktop destinations and styles load on demand under explicit lifecycle
  ownership and bundle budgets, while inactive workspace views remain mounted
  and correctly sized.

## Security boundaries are now explicit

- Local and remote daemon clients authenticate with workshop credentials.
  Protected routes declare capabilities and requests carry typed principals;
  unauthenticated loopback access is no longer trusted implicitly.
- Session, vault, artifact, media, Git, and Coder paths stay behind typed
  identifier and filesystem authority through the final read or write.
- Remote browser WebViews are isolated behind bounded native actions, hardened
  content-security policy, and packaged-resource checks.
- Secrets live in the platform credential store, remain scoped to their owning
  workshop, and honor revocation across reconnects.

## Upgrade notes

- Restart Medousa after updating so the app, bundled daemon, and optional
  package sidecars all run the 0.10.0 train. Update the mobile app as well to
  receive the embedded daemon and schema migrations.
- Existing vaults, sessions, conversations, prompt drafts, projects, Forge work,
  account connections, and local-model configuration are preserved. Storage
  migrations and index rebuilds run under daemon ownership.
- Custom HTTP clients that relied on unauthenticated loopback access must move
  to the current authenticated SDK/bootstrap flow. The shipped app, CLI, TUI,
  and SDK clients already do this.
- Companion integrations remain on their independent 0.2.0 release line.
