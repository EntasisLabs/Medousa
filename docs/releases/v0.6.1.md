## Highlights

### Windows WebView idle CPU
Hidden popout windows (chat, sticky note, browser, toolbar, view, guide) are created on demand on Windows instead of at launch. Show/hide also syncs WebView2 controller visibility so Task Manager no longer shows busy Manager / Network / GPU processes while the app sits idle.

### Shared idle hygiene
Popouts only connect as workshop observers while visible. Status activity pulse and peer unread / notification polls stop when the window is hidden.

---

## Upgrade notes

- **App only** — no engine API change; existing **0.6.0** workshops keep working.
- In-app updates: Settings → Workshop → App → Check for updates after publish.
- Ship path: Actions → **Release** → enable **`ship_desktop`** only; leave **`reuse_r2_daemon`** on (default) so the workflow fetches `medousa_daemon` from published `engine-v0.6.0` R2 artifacts and does **not** rebuild the daemon.
