# Medousa 0.7.2

**A Windows Forge reliability patch for the 0.7 coding room.**

This is a **full-train patch release**. Engine, adapters, MCP gateway, coding
engine, shell session, local brain, desktop, and installer artifacts all carry
the **0.7.2** channel stamp.

## Fixed

- Empty Git repositories are represented as an explicit not-ready state rather
  than suggesting an unborn `main` or `master` branch as a usable commit. Home
  explains that an initial commit is required and prevents project creation.
- A starting branch that was renamed or deleted now produces a specific,
  actionable conflict instead of a raw `git rev-parse` failure.
- Forge snapshot caches use unique temporary files and Windows-native atomic,
  write-through replacement. Project creation, loading, and recovery no longer
  attempt to open a Windows directory as a regular file or fail with
  `Access is denied (os error 5)`.

## Upgrade notes

- Restart Medousa after updating so the desktop replaces the bundled daemon and
  workshop sidecars with the 0.7.2 packages.
- Existing projects, work histories, workspace tabs, and terminal sessions are
  preserved. A project whose recorded base branch no longer exists requires an
  explicit branch choice; recreate an unprovisioned draft against that branch.
