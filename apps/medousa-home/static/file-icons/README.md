# Vendored file icons

This directory is not first-party Medousa artwork. It contains 615 SVG file
icons copied unchanged from `material-icon-theme@5.37.0`.

- Upstream: [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)
- License: MIT, Copyright (c) 2025 Material Extensions
- Documented upstream sources: [Material Design Icons](https://pictogrammers.com/docs/general/license/) and [Material Symbols](https://github.com/google/material-design-icons)
- Repository notice: [../../../../THIRD_PARTY_NOTICES.md](../../../../THIRD_PARTY_NOTICES.md)

The association data is generated alongside the icons at
[`src/lib/code/materialIconTheme.json`](../../src/lib/code/materialIconTheme.json).
To refresh this bundle after a dependency update, run
`node scripts/sync-file-icons.mjs` from `apps/medousa-home`.
