# Views and environments

Custom views let you pin a working surface — a canvas, a board, a tailored layout — without pretending everything is a chat transcript.

## Environments

An **environment** describes how the shell presents surfaces: which ones exist, how they lay out, and which presets you can switch. Layout presets in the status area (when available) swap arrangements for different jobs.

## Custom views

Create and name views for recurring work. They appear in navigation like built-in surfaces. Pop a view into its own OS window via the view pop-out when you want it on a second monitor or beside another app — same hide-on-close pattern as other pop-outs.

## Canvas and layout

Environment canvases and layout editors are for arranging how Home feels. Prefer small, intentional layouts over dashboard sprawl. One composition per desk beats a wall of cards.

## When to use a view vs a note

| Use a view when… | Use a note when… |
|------------------|------------------|
| You need persistent spatial layout | Prose and links are enough |
| Multiple widgets must stay visible | You're drafting or journaling |
| The surface is interactive | The agent should edit markdown |
