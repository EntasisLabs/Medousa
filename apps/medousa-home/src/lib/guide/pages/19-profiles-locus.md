# You and the Map

**You** is who Medousa knows you (and other people) as. **Map** shows recent chats and linked notes. Neither is the same as an imported Agent.

Related: [Architecture and terminology](guide:architecture) · [Sharing and phone](guide:sharing-phone) (Shared seats)

## You (Profiles)

Dock / More → **You**. Create menu:

| Action | Dialog |
|--------|--------|
| **Teach** | **Teach Medousa** — facts and preferences |
| **Add person** | **Remember someone** |
| **Add profile** | **New profile** (another hat / seat identity) |

Correct mistakes: focus a card → **That's not right** (prefill teach), or shelf **Correct or refine** / **Relationship** / **Value**.

Overflow: **Export/Import profile backup**, **Export identity notes**.

In Shared mode, seats bind profiles to one shared vault — see [Sharing and phone](guide:sharing-phone#shared-mode).

## Map (Locus)

Surface **Map** (full title: Session link map).

| Control | Role |
|---------|------|
| **Browse moments** | Dock moments list |
| **Filter by posture** | AVEC posture filter |
| **Search map…** | Find nodes |

Node kinds in the legend: **Session**, **Moment**, **Note**. Edges connect sessions, notes, and moments visually (types are not all labeled in a legend). Click through to reopen chat or notes when the node allows.

```callout
tone: note
title: What the map keeps
body: The map helps you navigate continuity. Deleting a session (Chat sidebar) also removes related Locus memory for that thread — irreversible.
```
