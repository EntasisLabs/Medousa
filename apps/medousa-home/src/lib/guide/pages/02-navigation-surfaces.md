# Navigation and surfaces

Medousa is organized as **surfaces** you switch between — Chat, Vault, Web, Automations, custom views — not as a stack of unrelated apps.

## The rail

The left rail is your primary switcher. Items map to surfaces (and nested recents where it helps). Use it for big context changes; use panes for side-by-side work inside a desktop.

## Surfaces

A **surface** is a full workspace mode: its own chrome, sidebar habits, and often its own summon toolbar. Built-ins include chat, vault/work, web, peers, settings, and more depending on your layout. Custom views you create also appear as surfaces.

Spotlight can jump you to a surface by name — faster than hunting the rail when you know where you're going.

## Shell tabs and panes

Inside a desktop you can split the work area:

- Split right / down
- Focus panes with keyboard (see [Keyboard and flow](guide:keyboard-flow#panes))
- Zoom a pane when you need focus
- Tabs within a pane for chat sessions, notes, or browser pages

Treat panes like a light tiling manager for one workshop session — not like opening twelve Home windows.

## Desktops

Virtual desktops (workspace marks in the status bar) let you park layouts. Rename them when a desk has a job ("Writing", "Debug", "Review"). Switching desktops should feel like walking to another bench, not reloading the app.

## Pop-outs and the desktop toolbar

Some tools leave the main window:

| Window | Role |
|--------|------|
| Chat pop-out | Full chat away from the shell |
| Vault sticky | Floating note |
| Web | Dedicated browser window |
| View pop-out | A custom view as its own window |
| Desktop toolbar | Slim always-on strip to summon the above |
| Operator's Guide | This manual |

Open the desktop toolbar from Spotlight (**Toggle desktop toolbar**) when you want Home to stay in the periphery.

```callout
tone: note
title: Pop-outs hide; they do not quit
body: Closing a pop-out window usually hides it so state stays warm. Use the same control again to bring it back.
```

## Summon toolbars

Some surfaces grow a contextual toolbar (library, automations, etc.). Mouse-shake can summon it if enabled — useful when chrome is tucked away. Prefer keyboard when you already know the binding.
