# Find answers

Short answers to common questions. Each link opens the full chapter when you want more detail.

## I want to chat with Medousa

Open **Chat** from the left rail (or the Chat tab on phone). Type at the bottom and press Enter to send.

Under the chat box you can change **Voice** (personality), **Stance** (short or deep answers), and which **Runtime** runs the turn — leave those alone until a turn needs them.

→ [Chat](guide:chat)

## I want to save something important

Open **Library** → **Notes**. Create or open a note. Medousa saves as you go (you’ll see Saving… / Saved).

Prefer notes in the Library for anything Medousa should remember later. Pop a note into its own window if you want it beside another app.

→ [Vault and notes](guide:vault-notes)

## I want to change how it looks

**Settings → Preferences → Look** — light or dark, and a color theme. Zoom the whole window from Spotlight (**Zoom in / out**) on the desktop app.

→ [Themes](guide:themes-customization)

## I want to use it on my phone {#phone}

On the **computer** that runs Medousa: **Settings → Sharing → Phone** → show the pairing QR (or code). Scan it with the phone app on the same Wi‑Fi.

The phone is a window into that computer’s workshop — not a second separate brain.

→ [Sharing and phone](guide:sharing-phone) · [Getting started](guide:getting-started#phone--companion-first-run)

## It says Offline / I can’t send {#offline}

1. Look at the status bar — **Offline** or **Connecting…**?
2. Open **Settings → Workshop**. Confirm the workshop is selected.
3. On desktop, try **Start** / **Restart**, or **Save & test** on the address.
4. On phone, check Wi‑Fi and that the computer is on and reachable.

→ [Troubleshooting](guide:troubleshooting) · [Getting started](guide:getting-started#first-connection-checklist)

## It asked me to Allow or Approve {#allow-or-approve}

- **Allow / Deny** — Medousa wants permission for a tool (for example opening something on your computer). Deny if you’re unsure.
- **Approve / Deny** (more tool rounds) — a long task wants to keep working. Approve only if you still want that work to continue.

→ [Permissions, budgets, and tool safety](guide:permissions-budgets) (plain overview at the top)

## My notes or chat look empty

You may be on the **wrong workshop**. Check the workshop name in the status bar and switch if needed. Each workshop has its own notes and conversations.

→ [Getting started](guide:getting-started) · [Workshops and connections](guide:workshops-connections)

## What do the words workshop and engine mean?

- **Workshop** — the place your notes, chats, and settings live (often this computer).
- **Engine** — the process that runs Medousa behind the scenes. Restart it from Settings → Workshop if things are stuck (active chats pause briefly).

→ [How Medousa fits together](guide:architecture)
