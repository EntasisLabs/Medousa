# Getting started

Get connected, send a first message, and know where your notes live. For word meanings, see [How Medousa fits together](guide:architecture).

## What you need

1. The **Medousa** app on a computer (or the phone app pointing at that computer).
2. A **workshop** — usually this computer.
3. Optionally a way for Medousa to answer — cloud models with an API key, or the optional Offline brain package.

No account is required. Your notes stay on your workshop.

## First time on a computer

On desktop, onboarding happens inside Home itself. You choose what you want nearby, shape the first desktop, choose a Medousa mark and matching theme, then optionally add a brain. Home can open while optional tools continue downloading.

```steps
title: Welcome wizard
subtitle: What each step is for

---
label: Focus
body: Choose code, messages, notes, planning, or Medousa assistance
status: done
---
label: Layout
body: Start focused, side by side, or with a small dashboard
status: done
---
label: Style
body: Name Home and pair one of the approved Medousa marks with its color theme
status: current
---
label: Brain
body: Optional — offline on this computer or your own provider key
status: pending
---
label: Ready
body: Enter Home; selected coding and channel packages can finish in the background
status: pending
```

Messaging adapters download only for the channels you selected. You can skip the Offline download and add models later under Settings.

### Already set up?

You may see **Welcome back** instead of a blank wizard. Choose **Continue**.

### Run the wizard again

**Settings → Connection → More on this device → Welcome wizard → Re-run** (desktop). Useful to revisit model choice or phone pairing.

## First time on a phone {#phone--companion-first-run}

The phone connects to your computer’s workshop — it doesn’t install a separate Offline brain.

1. On the computer: **Settings → Sharing → Phone** → show the QR or code.
2. On the phone: scan or enter the link / address.
3. Wait until the connection looks healthy.

## First connection checklist

```steps
title: Prove you’re connected

---
label: Pick the workshop
body: **Settings → Connection** — confirm an active workshop
status: current
---
label: Check the status bar
body: Should say **Connected** (not Offline)
status: pending
---
label: Send a hello
body: Open **Chat** and send a short message
status: pending
```

If you’re Offline: edit the address → **Save & test**, or use **Start** / **Restart** on the desktop. Restart briefly pauses open chats.

```callout
tone: tip
title: Wrong workshop, wrong notes
body: If chat or notes look empty, check the workshop name in the status bar before rewriting your message.
```


```card
title: Optional phone
subtitle: Another screen
summary: Pair from **Settings → Sharing → Phone** when you’re ready.
```
Day to day: **ask** in chat, **keep** what matters in Library, **return** with the rail or Spotlight — you shouldn’t need to relaunch the whole app for one note.
